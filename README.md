# 📈 Habit Tracker & Analytics Board

## Overview
A polished, full-stack application designed to help users track their daily habits, build consistent streaks, and view progress analytics. Built to master the basics of the MERN stack.

## Features
- Create, read, update, and delete daily habits.
- Toggle daily completion and automatically calculate current/longest streaks.
- Minimalist dashboard built with Tailwind CSS.

## Tech Stack
- **Frontend:** React, Tailwind CSS, Axios, React Router
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Deployment:** Vercel (Frontend), Render (Backend), MongoDB Atlas (Database)
